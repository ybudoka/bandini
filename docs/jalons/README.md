# Les jalons

← [le plan](../plan.md), qui ne garde que ce qui reste à faire

**Un fichier par jalon**, livré ou pas : sa **fiche** (ce qui est prévu, ou l'était) et ses **notes** (ce qui a été demandé, mesuré, livré, et pourquoi). Le plan les gardait toutes dans un seul fichier de 12 000 lignes ; elles ont été rangées ici le 20 sept. 2026, sans un mot changé.

La table ci-dessous liste les jalons **livrés**, dans l'ordre où ils l'ont été ; les lignes ⬜ sont dans [le plan](../plan.md), et leur fichier est ici aussi.

Deux documents d'avant la table :

- [Les jalons de la v1](les-jalons-de-la-v1.md) — le tableau d'origine, M0 à M8, avec « Vérifié par » ;
- [Le tri du 13 sept. 2026](le-tri-du-13-sept-2026.md) — la règle de priorité telle qu'elle a été écrite, et la table de tri d'alors.

⚠️ **Livrer une ligne**, c'est **déplacer sa ligne** : elle quitte la table du plan, devient `✅ **livré**` avec sa date et s'ajoute **en bas** de la table ci-dessous. Son fichier ne bouge pas : sa fiche y est déjà, et sa note de livraison s'écrit dessous, sous « Notes ». Le juge (`scripts/verifier_table_des_jalons.py`) refuse une ligne ⬜ ici et une ligne ✅ dans le plan.
